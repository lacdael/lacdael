Virtual Terminal Client

📅 04/06/2026, 01:00:00

The ISOBUS standard allows for the creation of custom control systems. As a demonstration, a Virtual Terminal (VT) is used with a VT client connected to a pump and a flow meter to create a minimal watering system.

Watch the Video

VT Client

To interact with an ISOBUS Virtual Terminal (VT), a VT client must perform the following steps as defined by the standard:

  1. Undergo CAN bus address claiming.
  2. Listen for the VT status message.
  3. Send the Working Set Master message.
  4. Begin transmitting VT client status messages.
  5. Upload its serialised user interface using the transport protocol for packetisation.
  6. Send user interface updates and listen for user interface events.

I used Pool Edit to create a minimal ISOBUS user interface consisting of a bar graph and two buttons.

The VT client hardware is connected to a pump through a PWM driver and to a flow meter connected to an input pin configured with an interrupt to monitor pulse counts.

Once the VT client is initialised, the calculated and scaled flow rate value is sent to the VT to update the bar graph on the user interface using an object ID reference.

When a button is pressed on the VT, a message is sent to the VT client containing an object ID reference and a key code value. The VT client then performs the action associated with that object ID and key code. In this demonstration, the action adjusts the PWM output, which controls the pump speed.
