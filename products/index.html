BLE MIDI Sequencer

Binary files to make your own : https://github.com/lacdael/music_modules/tree/main/midi_player_ble This is an assembled, free UK shipped, firmware flashed offering of the midi_player_ble module - The sequencer lets you input a 1 octave, 2 velocity level sequence, with a maximum of 8 bars, making 128 1/16th notes. - Settings: root note selection, major/minor key selection, bar length selection,bpm selection, Clear sequencer pattern, midi channel selection, note hold selection, note randomiser, velocity, There are 3 variable midi control channels, with sliders for the values.
